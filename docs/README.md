# 工作日志

本目录保存项目开发、调试与验证记录。当前项目进度见 [AGENTS.md](../AGENTS.md)。

## 记录方式
按日期创建 YYYY-MM-DD.md，同一天的后续工作追加到同一文件。完成工作后同步更新 AGENTS.md 的进度和日志索引。

## 日志模板
```markdown
# YYYY-MM-DD 工作日志

## 任务名称
### 目标
- 本次任务目标。

### 完成内容
- 实际修改及相关文件。

### 验证结果
- 检查命令与结果；未执行时说明原因。

### 问题与后续事项
- 尚未解决的问题及下一步工作；无则写“无”。
```
